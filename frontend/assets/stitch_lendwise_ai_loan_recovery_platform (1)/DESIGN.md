## Brand & Style

This design system embodies the prestige, precision, and technological authority of elite cloud infrastructure and enterprise intelligence tools. It targets forward-thinking engineering leaders, high-growth founders, and data architects who expect a digital workspace with visceral speed, deep focus, and high aesthetic refinement. 

The aesthetic synthesizes **Dark Luxury Minimalism** with **Hyper-Refined Glassmorphism**. The visual plane rests on near-black, deep void tones illuminated by directional radiant energy—electric blues, sharp cyans, and ambient violet blooms. Crisp structural grid-lines, semi-transparent frosted surfaces, and finely tuned radial luminance layers establish a sense of optical weight and physical depth without clutter. The experience feels fast, sophisticated, and calculated.

## Colors

The foundation is built on deep cosmic values: `#06090F` provides absolute depth at the page floor, while `#0B0F19` and rich indigo-tinted navy (`#0F172A`, `#111827`) define elevation strata. 

Chromatically, vibrant Electric Blue (`#3B82F6`) anchors primary interaction, complemented by luminous Cyan (`#06B6D4`) and deep Violet (`#8B5CF6`). These vivid accents are used deliberately:
- Primary interactive paths and focus rings utilize `#3B82F6`.
- Metric indicators, live telemetry, and forward-looking data points highlight in `#06B6D4`.
- Secondary highlights, gradient blends, and feature callouts tap `#8B5CF6`.
- Borders combine ultra-subtle frosted glass edges (`rgba(255,255,255,0.08)`) with dynamic state-based photon glow edges (`rgba(59,130,246,0.2)`).
- Neutral text layers use `#F9FAFB` for primary optical clarity, backed by `#94A3B8` and `#64748B` to control reading cadence.

## Typography

The typographic hierarchy relies on a pairing between the modern geometric curves of `Manrope` and the calibrated technicality of `JetBrains Mono`.

- **Display & Headlines:** Set in `Manrope` with heavy weights (700–800) and compact negative letter-spacing (`-0.02em` to `-0.03em`). Emphasize brand narratives by intertwining solid white headline text with radiant linear gradient fills (`#3B82F6` to `#06B6D4`) or light italicized modifier words to direct the reader's eye.
- **Body:** Standardized on `Manrope` Regular (400) at 15px with relaxed line-heights for legibility against dark slate surfaces.
- **Telemetry, Micro-copy & Badges:** `JetBrains Mono` provides tabular stability for data points, version indicators, timestamps, and metric values. It brings engineering credibility and high scannability to dense dashboards.

## Layout & Spacing

The layout is built upon a 12-column adaptive fluid grid constrained to a maximum content width of 1280px to preserve visual density. The spacing rhythm is derived from an exact 4px/8px modular base:

- **Desktop (≥ 1024px):** 12 columns, 24px (1.5rem) gutters, 32px (2rem) outer margin. High-density dashboards use grouped container sections separated by 40px (2.5rem) gaps.
- **Tablet (768px – 1023px):** 8 columns, 16px (1rem) gutters, 24px (1.5rem) outer margin. Cards stack into 2-column arrays.
- **Mobile (< 768px):** 4 columns, 12px (0.75rem) gutters, 16px (1rem) outer margin. Complex multi-metric components collapse into horizontally swipeable tracks or single-column linear stacks.

Paddings and gap structures (`space-*`) remain consistent across cards and widgets: standard card padding uses `space-lg` (24px), while compact utility rows and status bars use `space-sm` (8px) and `space-md` (16px).

## Elevation & Depth

Visual hierarchy is achieved through **multi-layered frosted glassmorphism** and **ambient radial light spills** rather than blunt drop-shadows.

1. **Base Layer (Canvas):** The infinite plane at `#06090F` featuring fixed ambient background glows—soft, low-opacity radial gradients (300px to 600px blur radius) in `#1E3A8A` and `#4C1D95` positioned behind key focal areas.
2. **Surface Layer (Containers & Grid Panels):** Tinted navy-indigo (`rgba(17, 24, 39, 0.7)`) backed by a `backdrop-filter: blur(16px)` and framed with a micro-border of `1px solid rgba(255, 255, 255, 0.08)`.
3. **Floating Layer (Modals, Hovered Cards, Menus):** Elevated to `rgba(15, 23, 42, 0.85)` with `backdrop-filter: blur(24px)`, a top-edge highlight stroke (`rgba(255, 255, 255, 0.16)`), and a diffused shadow: `0 20px 40px -15px rgba(0, 0, 0, 0.7), 0 0 20px 0 rgba(59, 130, 246, 0.15)`.
4. **Active/Interactive Layer:** Focused elements engage an inward border illuminate using `1px solid rgba(59, 130, 246, 0.6)` combined with a faint outer halo (`box-shadow: 0 0 16px rgba(59, 130, 246, 0.25)`).

## Shapes

This design system uses a balanced **rounded corner architecture** (Level 2) that softens dark surfaces while preserving structural precision:

- Standard cards, dashboard panels, and modals use `rounded-lg` (16px / 1rem) to frame data cleanly.
- Buttons, inputs, drop-down triggers, and interactive widgets leverage `rounded` (8px / 0.5rem).
- Metric chips, status pills, category tags, and avatars use fully rounded caps (`rounded-full` / 9999px) to provide organic contrast against rectangular grid modules.
- Nested elements always maintain concentric geometry: parent containers with 16px radius host child elements with 8px radius at 8px offsets.

## Components

### Buttons
- **Primary:** Filled with an electric blue gradient (`linear-gradient(135deg, #3B82F6 0%, #2563EB 100%)`), text in `#F9FAFB` (Manrope SemiBold 14px), 8px border-radius, padded 12px 20px. Features an ultra-thin inset border highlight `inset 0 1px 0 rgba(255,255,255,0.2)`. On hover: subtle scale `1.01` and an energetic cyan-tinted glow (`box-shadow: 0 4px 20px rgba(59,130,246,0.4)`).
- **Secondary (Glass):** Frosted navy surface (`rgba(17,24,39,0.6)`), border `1px solid rgba(255,255,255,0.08)`, text `#F9FAFB`. On hover: surface transitions to `rgba(30,41,59,0.8)` with border changing to `rgba(59,130,246,0.3)`.
- **Tertiary (Ghost):** Transparent background with `#94A3B8` text; hover produces a subtle `#111827` backing and brightens text to `#F9FAFB`.

### Badges & Status Chips
- Pill-shaped (`rounded-full`), padded 4px 12px.
- Backgrounds use 12% to 15% opacity tint of their respective accent color (`rgba(6,182,212,0.12)` for info, `rgba(139,92,246,0.12)` for compute/AI, `rgba(59,130,246,0.12)` for standard statuses).
- Typography set in `JetBrains Mono` 11px uppercase with `0.06em` letter spacing. Left-aligned pulsating status dot (6px circle) embedded for real-time states.

### Input Fields
- Background `rgba(15,23,42,0.6)` with backdrop blur, border `1px solid rgba(255,255,255,0.08)`.
- Text is `#F9FAFB`, placeholder text is `#64748B`.
- Height: 42px; inner padding 10px 14px; radius 8px.
- Focus state: border transforms to `#3B82F6` accompanied by a soft blue ring `0 0 0 3px rgba(59,130,246,0.2)`.

### Cards & Panels
- Constructed with `rgba(17,24,39,0.7)` fill, 16px corner radius, and `1px solid rgba(255,255,255,0.08)` stroke.
- Header bars include subtle bottom dividers (`rgba(255,255,255,0.04)`).
- Featured or active cards layer a top-edge linear gradient line (`linear-gradient(90deg, transparent, #3B82F6, transparent)`) along the upper 1px border.

### Checkboxes & Radio Buttons
- 18px boxes with 4px corner radius (checkbox) or circular (radio), border `1px solid rgba(255,255,255,0.15)`, background `rgba(15,23,42,0.8)`.
- Checked state: background snaps to `#3B82F6` with sharp white SVG icon check or center dot, accompanied by an instant 8px ambient glow.

### Lists & Data Tables
- Row dividers use hairline borders (`1px solid rgba(255,255,255,0.04)`).
- Alternate row striping is avoided; instead, individual rows reveal an instantaneous glass highlight (`rgba(255,255,255,0.02)`) on hover.
- Data columns featuring numeric metrics leverage `JetBrains Mono` right-aligned for clean scanning.
